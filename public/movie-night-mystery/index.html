GitHub Pages & SharedArrayBuffer Instructions

GitHub Pages & coi-serviceworker Architecture

Multi-threaded WebAssembly in modern browsers relies on SharedArrayBuffer. Browsers strictly mandate Cross-Origin Isolation via two HTTP response headers: 

Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp

Because GitHub Pages is a static host that does not support custom HTTP response headers, coi-serviceworker.js intercepts all network requests client-side, dynamically attaching these headers to make FFmpeg.wasm function without any server infrastructure.

Deployment Checklist:
1. Place coi-serviceworker.js in your repository root alongside index.html.
2. Reference it as the very first script inside <head>.
3. On initial page load, the worker claims the client, reloads once transparently, and permits full multi-threaded WebAssembly execution.
